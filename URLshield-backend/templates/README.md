# Brand Templates for SSIM Comparison

This folder stores legitimate brand screenshots that are compared against live website captures during phishing analysis. The SSIM-based brand matching logic uses these template images to estimate how visually similar a suspicious page is to a trusted brand.

## Folder purpose

The templates live under:

```text
URLshield-backend/templates/
```

Each brand is stored in its own folder, for example:

```text
URLshield-backend/templates/
├── airtel_in/
│   ├── screenshot.png
│   └── metadata.json
├── bankofbaroda_in/
│   ├── screenshot.png
│   └── metadata.json
├── hdfcbank_com/
│   ├── screenshot.png
│   └── metadata.json
└── ...
```

## What the script does

1. Visits each brand domain in the configured list
2. Captures a screenshot
3. Resizes the image to 800x600
4. Saves the PNG and metadata JSON in the corresponding template folder
5. Prints a verification summary after capture

## How it is used

The project compares a captured page against the template screenshot for the detected brand and computes a similarity score. This supports the SSIM-based detection flow in the phishing analysis pipeline.

If a specific template is outdated or wrong, delete that brand folder and rerun the script to regenerate it.

## Notes

- Screenshots are stored as PNGs and optimized for size.
- Metadata includes the original domain, capture timestamp, and image size.
- This directory is used as the trusted comparison base for phishing visual similarity checks.
